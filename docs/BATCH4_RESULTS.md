**Task 2 choice: option 2, no rule change.** Computing accuracy on read needs the official results in every reader, so it was not cheap. "Recalculate Accuracy" is admin-only for FTC and shows its error. Note: without FTC API keys the lookup has no matches, so a recalculation writes "n/a" accuracy (as in FRC).
