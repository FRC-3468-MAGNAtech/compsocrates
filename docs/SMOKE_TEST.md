# Smoke test: CompSocrates v2 beta

Run it on the Vercel PREVIEW of `release-prep` first (step 7 of `docs/GO_LIVE_CHECKLIST.md`), then again on compsocrates.com right after the release. **A preview uses the same Firebase project and the same Blob store as the live site, so every write below is real production data.** Use a TEST event and a TEST team where it says so, and clean up afterwards. Needs: one existing CS account on a real team (a member who can scout), the platform owner account, and one throwaway email address.

Steps that WRITE real data are marked **[WRITES]**.

1. **Existing CS account signs in.** Sign in at `/login`. Expected: you land on the FRC dashboard (`/frc/dashboard`); with no remembered program on this device you see the FRC / FTC selector first, so pick FRC. Your team name and number, the team's selected events and your own selected event are there, and the theme is yours (or the CompSocrates default if none was stored).
2. **An old CS URL redirects.** Open `/event-selection`, then `/pick-list`, then `/scout-form`. Expected: they land on `/frc/event`, `/frc/analytics/pick-list` and `/frc/scout`, with no 404 and no sign-in loop.
3. **Match Scout form submits to a TEST event. [WRITES]** On the Scout page pick a TEST event (a test event key on the team, not a real competition), fill a match and submit. Expected: a saved confirmation, and the entry appears in Match Scout analytics for that event. Clean up: delete the test entry from the team's Admin Panel > Entries (or ask the owner). Never submit to a real event during a smoke test.
4. **Scout Accuracy and Practice Sessions show data.** Open Scout Accuracy and Practice Scouting. Expected: the team's existing history is listed (not an empty list and not an error banner). If a read fails the page says so; an empty list with no message is a defect.
5. **Event names resolve with the year.** Check Event Select, Match List and Analytics. Expected: every event shows its name and year (for example "2026 ..."), not the raw key. Without the TBA key set, expect the raw key with a named "key is not configured" notice (that is a configuration problem, not a pass).
6. **Logo and favicon.** Expected: the favicon shows in the browser tab, the pages show the text product name (no placeholder logo exists), and nothing shows a broken image.
7. **Changelog and Credits, signed out and signed in.** Signed out: open `/credits` (loads, no login). Signed in: open Changelog and Credits inside the app. Expected: current entries first, the old CS entries marked Legacy below them, the unread dot only for non-Legacy entries; Credits shows the same text signed out and signed in.
8. **Sign out resets the theme.** Pick a non-default theme or colour mode, sign out. Expected: the signed-out pages use the default theme, and signing back in restores yours.
9. **FTC selector and an FTC page.** Open `/?choose=1`. Expected: both FRC and FTC cards. Choose FTC with the existing CS account. Expected: because that account has no FTC profile, the FTC team setup screen loads ("Join a team", then "Create a team"); the Create tab says applications to create a team are not open yet, and there is no form to create a team. (If you have an FTC test account on a test FTC team, its dashboard loads instead.)
10. **A brand-new account lands on setup and cannot create a team. [WRITES]** Sign out, then sign up at `/signup` with the throwaway email. Expected: you land on a setup screen with a working Sign out button and no team is created: FRC shows the application route ("Apply to create a team"; do NOT submit an application), FTC shows the "not open yet" notice. Check in the Firestore console that no new document appeared in `teams` or `programs/ftc/teams`. Clean up: delete the throwaway user in Firebase console > Authentication and its `users/{uid}` document.

Also look, on the first load of each step, at the browser console and the Network tab for red errors (permission-denied, 503, 401 loops). Any permission-denied on a collection means the rules were not deployed first: stop and go back to the checklist.
