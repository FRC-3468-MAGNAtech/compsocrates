**Where I differ from the brief (please check).** (1) **There is no Templates tab in FRC.** Its `templates` tab id is the owner-only Template Review; the team's templates are the "Templates" view INSIDE the Forms tab. I ported them there (list, save from a form, edit, delete, apply) and added no FTC tab id, so FTC has 9 tabs, not 10. `admin.templateSharing` (off for FTC) hides public templates and "request to publish". (2) **Backups show counts after the file is made** (FRC's flow, shared) rather than before the download: a pre-download step would have changed FRC. (3) The Sessions list says **"No official score"** for a completed session with no accuracy; FRC's list said "?", so this wording is now shared (display only).
**Forms.** Store, `setActiveForm`, audit and the template service take the program (default unchanged; `firestore-store.test.ts` proves FRC still uses root `forms`/`teams`, FTC `programs/ftc/...`). Seasons come from `useForms()`, not the root list. **Active form moved:** FTC now picks it in Forms > "Set as active" like FRC; Batch 5a's Team Settings card, `ActiveFormsSection` and `teamSettings.activeForms` are removed. **Sessions.** Shared panel, now through `program`: lookup, detail, dismiss, exclude, Hard Reset (confirm + audit) all pass the program; live/lobby kinds hidden in the filter where the feature is off; load error shown (`LoadError`); malformed sessions are listed with an amber "couldn't be read in full" badge. **Rescore.** Event and session tabs pass the program (seasons from the program, library refresh through `library.importSchedule`). Writes ONLY derived fields: session `accuracy, scoutedTotal, officialScore, penaltyPoints, flags`; entry `score` (events: `accuracy, autoFlags`); never `values`. Chunks of 400 (`rescore-apply.ts`); a failed chunk stops with "N of M written, run again"; idempotent. A session whose match has `scoreKnown === false` is skipped and counted (FRC matches never set it, so FRC is unchanged); for a program with its own store an entry with no official score is left as it is and counted, and admins' flag dismissals survive. Dry run shows counts and a sample, then an explicit Apply. Audit entry lists fields and skips.
**Backups.** Export only (FRC has no restore, so **restore is not ported**). `ProgramData.backup` reads team-scoped equality queries: entries, form entries, sessions, assignments, attendance, audit log, forms + versions, own templates, library (`origin == "api"` and `teamId ==`), roster, team doc, sidebar. Never in the file: `joinCode`, emails, tokens, secrets (`lib/ftc/backup.ts`); the roster has ids, names and roles only. File names its `program`; FRC's file is unchanged.
